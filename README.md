Financial News Market Insight Bridge is a content visibility and AI discovery bot designed to help Financial News articles gain greater discoverability across AI platforms, search engines and relevant digital channels. Built by [FinancialNews.it.com](https://financialnews.it.com).

## Key Functions

- **AI Visibility** — Supports greater discoverability of Financial News content across AI platforms
- **Content Discovery** — Identifies relevant finance and business topics connected to published articles
- **Topic Matching** — Matches articles with related subjects, keywords and financial concepts
- **Contextual References** — Organizes relevant content references around finance related topics
- **Search Visibility** — Supports content discoverability across search focused environments
- **Article Organization** — Structures Financial News articles by topic, category and relevance
- **Finance Topic Mapping** — Connects content across investing, banking, fintech, crypto, markets and economics
- **Content Reach** — Helps relevant Financial News information reach audiences searching for related financial topics

## Core Coverage

Finance · Investing · Stock Market · Banking · Fintech · Crypto · Economy · Personal Finance · Wealth Management

## Features

- AI Visibility Score — measures discoverability across AI platforms and LLM responses
- Content Discovery Score — evaluates topic identification and article relevance mapping
- Topic Matching Score — assesses keyword and financial concept alignment
- Search Visibility Score — tracks search engine content discoverability
- Article Organization Score — measures content structure and categorisation quality
- Finance Topic Mapping Score — evaluates cross-topic connections across finance categories
- CLI support in Node.js and Python
- Benchmark dataset included (20 financial news insight cases)
- Lightweight, publish-ready, minimal dependencies

## Quick Start

### Node.js

```bash
npm install @financial-news/market-insight-bridge
npx financial-news-bridge "article-title" investing 88 82 85 78 90 80
```

### Python

```bash
pip install financial-news-market-insight-bridge
python -m insight_bridge "article-title" investing 88 82 85 78 90 80
```
